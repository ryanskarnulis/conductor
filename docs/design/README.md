## Source only

These came from claude.ai's Design and Design System editors. The `.dc.html` files need that editor's runtime to render, so treat them as source. `/_blob/<id>` references point to the files in `assets/`, named by the same id.

- `design-system/`: the Conductor design system ([artifact](https://claude.ai/artifact/QWR5kpuitBY2rJYz1eFxN7)) — README, tokens, component guidelines and previews, motion, scene, sound, icons.
- `concepts-2026-11-05/`: the first concept round — [A · Living Web](https://claude.ai/artifact/7M9kx8ewxVCpbut8pF5A1z) (picked), [B · Orrery](https://claude.ai/artifact/R32uqrCvd79z5oWwxcuYGV), [C · Tape](https://claude.ai/artifact/XNsLW2iaky3JQoSvmLmxkE). The Notes boards hold each concept's rules.

Glitch Lab (the 3D mascot, #93) lives in `gateway/docs/design/`.
