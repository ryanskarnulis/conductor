# Icons

Lucide v1.24 (ISC licence), the icons conductor's frontend imports from `lucide-react`, exported as SVG. Each draws a 2px round-capped stroke in `silk` (#c7d3e4), because an `<img>` cannot inherit colour; to colour one, use the lucide component instead.

- `waypoints`: the Conductor mark, in an `info-soft` disc (MessageBubble avatar).
- `mic`, `ear`: the mic button, idle and listening (Composer).
- `triangle-alert`: a failed delegate call (SideThread).
- `list-tree`, `message-square-share`: delegate-call summaries and their replies (SideThread).
- `folder-plus`, `list-music`, `skip-forward`: the Sort panel's actions.
- `message-square-plus`: new chat. `send-horizontal`: Send. `trash-2`: delete a conversation. `volume-2`, `volume-x`: read replies aloud, on and off (Composer).
- `x`: close (Sort panel).
