# MemoryFact

MemoryFact shows one thing Conductor recalled from your own record, with where and when it came from. Intentional addition: the prototype shows recall only as a receipt; listed in #86.

## Use
Under the receipt of a `recall` step, or wherever Conductor uses something it remembered.

## The consumer provides
The source (your words, an app's record), the date, the quoted fact, and a Forget action.

## Rules
- Quote, never paraphrase. Show the date.
- `violet`, the same as step kinds: it is Conductor's own memory, not an app.
