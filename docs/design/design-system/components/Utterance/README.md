# Utterance

Utterance shows what you said, at the top of the panel: the request in `said`, and a short follow-up (a yes) in `said-again`.

## Use
While you speak it shows the live words and ends with an ellipsis; it settles when the utterance is heard. A new request replaces it.

## The consumer provides
The transcript text, and an optional follow-up.

## Rules
- Your words, quoted exactly. Never paraphrase or correct them.
- Label it `You`, never a name.
