# QuestionCard

QuestionCard is Conductor asking you something it needs to continue, with the answers it can offer. Intentional addition: not in the prototype yet; listed in #86.

## Use
When a plan cannot continue without a choice. It sits where a ConfirmationCard would, in the same amber, because the run is waiting on you.

## The consumer provides
The question, two to four choices as buttons (each with a short reason), and the spoken alternative.

## Rules
- Never a yes/no about a write: that is a ConfirmationCard.
- A spoken answer works as well as a tap. It lapses at the next turn, like a confirmation.
