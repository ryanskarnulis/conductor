# ProposalCard

ProposalCard offers something Conductor could do that you did not ask for. Intentional addition: not in the prototype yet; listed in #86.

## Use
After a run, when a receipt suggests an obvious next step. At most one at a time. Dashed `glow`, because nothing has happened yet.

## The consumer provides
One sentence naming the action and its object, and two actions: "Do it" and "Not now".

## Rules
- Doing it starts an ordinary run, with its own confirmation if the app asks for one.
- "Not now" dismisses it for this conversation. Never repeat it.
