# FinishedNote

FinishedNote reports a background job that ended, with its result and what you can do next.

## Use
When a job's receipt arrives, whether or not you are talking to Conductor. It is announced once; the music string plucks if sound is on.

## The consumer provides
The app, the time, a one-line result from the receipt, Undo when the receipt carries it, and an open handoff to the app.

## Rules
- `ok` border and fill: it only appears from a receipt.
