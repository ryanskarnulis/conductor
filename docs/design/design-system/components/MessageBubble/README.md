# MessageBubble

MessageBubble is a turn in the chat view: yours on the right in `info-tint`, Conductor's on the left beside the Waypoints mark.

## Use
The text-first chat page (`AgentPage`), and the history behind the Living Web panel. Three dots while a turn is working.

## The consumer provides
The speaker, the text (Conductor's renders as markdown), the time, and the working state.

## Rules
- The bubble corner nearest the speaker drops to 4px.
- Note turns (what you did in the UI) appear as your turn, never as an invented reply.
